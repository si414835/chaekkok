# 책콕 Supabase SQL (파이프라인 4~6단계)

계산은 Supabase DB 안의 함수가 하고, `compute_composite.py`가 매일 호출한다.

| 이름 | 종류 | 하는 일 |
|---|---|---|
| `refresh_book_state(날짜)` | 함수 | 그날 책 x 날짜 특징(분야 순위 변화·신규 진입·TOP10 머문 날·급상승·지난달 대출 증가·지역 수·최근 출간·사서 추천·출간 예정·유튜브/검색 급증)을 계산하고 모멘텀 점수, 신뢰도(상승 신호 개수), 트렌드 단계(포착·떠오름·확산·스테디), 이유 한 줄을 `book_state`에 쓴다 |
| `refresh_spotted()` | 함수 | 처음 포착·떠오름·확산이 된 날과 그 뒤 처음 분야 TOP10에 든 날을 `spotted_log`에 쓴다. 기준이 바뀌어 더는 포착되지 않는 책은 지운다 |
| `v_book_state_latest` | 뷰 | 앱이 읽는 최신 단계·이유 |
| `v_spotted_outcome` / `v_hit_stats` / `v_hit_books` | 뷰 | 적중 기록 페이지 (2주 안에 더 오른 비율, TOP10 진입 책, 평균 먼저 안 날) |
| `v_upcoming` | 뷰 | 요즘 뜨는 작가의 곧 나올 책 (국립중앙도서관 ISBN 출간예정) |

## 단계 판정 (위에서부터 먼저 걸리는 것)
1. **스테디**: 최근 21일 중 10개 분야가 모두 수집된 날의 90% 이상 분야 TOP10
2. **확산**: 모멘텀 45점 이상 + 상승 신호 2개 이상
3. **떠오름**: 7일 전보다 분야 순위 3계단 이상 상승, 분야 목록 신규 진입, 또는 전국 대출 급상승
4. **포착**: 요즘 뜨는 작가의 출간 예정 신작, 또는 순위권 밖/하위권이면서 (사서 추천·올해 신간) + (유튜브·검색 급증·대출 30%↑)

## 모멘텀 가중치
분야 내 순위 상승(목록 크기로 나눔, 0.3이면 만점) 35 · 신규 진입 15 · 전국 급상승 10 · 지난달 대출 증가(50%면 만점) 10 ·
최근 출간(올해 1, 작년 0.5) 10 · 사서 추천 5 · 지역 확산(8개 지역이면 만점) 5 · 유튜브 급증 5 · 검색 급증 5.
TOP10에 2/3 이상 머문 책은 15점 감점.

지난달 대출 증가·지역 확산·출간 예정은 '지금' 데이터라 최근 3일 계산에만 반영한다(과거 계산에 미래 정보가 섞이지 않게).
함수 원문은 Supabase 대시보드 Database > Functions 에서 볼 수 있다.

## 키워드·알림

| 이름 | 종류 | 하는 일 |
|---|---|---|
| `v_keyword_books` | 뷰 | 책마다 정보나루가 뽑은 키워드(book_usage.keywords)를 한 줄씩 펼침. 키워드 페이지에서 사용 (어린이 책 제외) |
| `push_subscriptions` | 표 | 휴대폰 알림 구독(기기별 endpoint, 콕한 책, 관심 분야, 알림 종류). 브라우저는 직접 못 읽고 `push-subscribe` 함수만 씀 |
| `get_vapid_private_key()` | 함수 | Vault에 둔 알림 비밀키를 꺼냄. service_role만 실행 가능 (send_alerts.py) |
